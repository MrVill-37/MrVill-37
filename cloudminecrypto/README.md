# CloudMineCrypto

An educational CLI app that explains self-mining tradeoffs, presents plan tiers, and estimates reward points.

## Important disclosure

CloudMineCrypto does not provide ownership of mining hardware or operation of a real Bitcoin mining rig. Reward estimates are illustrative only, may vary, and are not guarantees of future value.

## Commands

From this directory:

```bash
python3 cloudminecrypto_app.py compare
python3 cloudminecrypto_app.py plans
python3 cloudminecrypto_app.py estimate --plan starter --activity-score 1.3 --market-variability 0.2
```
